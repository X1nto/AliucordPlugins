# NitroSpoof
Modified version of the NitroSpoof plugin to add emotes to emojis using markdown links. so the emote `:trolley:` will be added as `[trolley](https://cdn.discordapp.com/emojis/916000825325780992.webp?size=48&name=trolley%7E4&lossless=true)` rather than just `https://cdn.discordapp.com/emojis/916000825325780992.webp?size=48&name=trolley%7E4&lossless=true`
**warning:** the plugin "MoreHighlights" is required for properly displaying the emote links on the mobile app.
